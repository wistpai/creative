# 為你寫一首詩｜永久入口

本目錄供既有 GitHub Pages（GitHub 靜態網頁服務）發布於 `/creative/poetry/`。不建立資料庫、不收投稿、不保存讀者信箱；投稿與私人管理使用獨立指令碼系統。

## 檔案

- `index.html`：計畫介紹、詩作社群、投稿入口、完整條款可展開區塊與公開聯絡方式。
- `style.css`：桌機及手機共用版面，優先使用霞鶩文楷，並提供繁體中文替代字型。
- `config.js`：正式投稿網址集中設定。日常更換部署網址時修改 `submissionUrl`；只接受正式 `/exec`，空白或格式不符會停用按鈕。
- `app.js`：更新投稿連結及安全停用處理，不傳送投稿或個人資料。
- `site-data.json`：只含公開設定與正式條款快照。不得放入完整私人備份或管理表資料。
- `terms/`：不可覆寫的各版條款全文、原文、雜湊與版本紀錄。
- `tools/build.mjs`：以正式後台快照重建入口及新增條款版本。

## 更新條款

先在私人管理介面保存新版本並下載「入口整合資料」，檢查只有公開設定，再替換 `site-data.json`。執行：

```sh
node poetry/tools/build.mjs
```

需要 Node.js（伺服器端 JavaScript 執行環境）22 以上，不須安裝套件。也可將公開整合檔路徑放在命令後面。工具會核對全文 SHA-256（安全雜湊演算法）雜湊；同一版號文字不同時會阻擋。所有舊版本必須保留。

發布後先確認完整條款深層網址及目前版號，再開放後台收件。更改投稿部署網址時，也應同步更新後台正式網址及本檔 `site-data.json` 的 `webapp`，以免日後重建還原成舊設定。

## 原首頁

上層 `index.html` 只新增「為你寫一首詩」卡片。既有曼陀羅小詩、兩項故事工具及創作六邊型的文字、連結與樣式均保留。

## 發布與檢查

沿用本儲存庫原有靜態網頁發布設定。確認 `/creative/poetry/`、條款版本網址與回到 `/creative/` 的連結可直接開啟，投稿按鈕指向實際 `/exec`。

無追蹤碼、會員或付款功能。網頁字型由 Google Fonts（Google 網頁字型服務）載入，失敗時改用本機替代字型。原創詩作文字適用的創用授權不自動涵蓋圖像、字型或讀者投稿原文。
